About

Problems First. Code Second. I got into coding because I needed to earn — no CS degree, no bootcamp, just a problem and the internet. I taught myself Python and Django, and not long after, built an invoicing tool and sold it to a local business. That was proof this works.

I build fast. I use AI tools the way a carpenter uses power tools — to deliver better work, quicker — but I know what's under the hood. I understand what I'm building.

Right now I'm open to freelance projects, contracts, and full-time opportunities. If you have something that needs building, I'm interested.
