# atlas-v1: the Atlas

Live 2026-10-28 to 2026-10-29. Git tag `design/atlas-v1` (commit `82ba441`).

- **Background:** a WebGL watercolour sea (`src/components/sky/`) that drifts on its own, stirs under the pointer and drops ink on click. Paper grain on top.
- **Work:** every project is an island card along a wavy sea lane. A small boat sails the lane as you scroll, leaving a wake (`Voyage.tsx`).
- **Hero:** a big headline with a brush stroke behind one word, and a "cartouche" card with a compass needle that follows the mouse, soundings (islands / live / tools / ∞) and a legend.
- **Sections:** Currents (things I make, as a drifting ticker), The voyage (four process ports), Questions, and a quote flow where the visitor's idea forms a new island as they answer.
- **Switches:** day / night and motion. Mobile bottom dock with a chart sheet.
- **Type:** Syne (display), Figtree (body), JetBrains Mono (labels). Accent `#2b36d9` by day, `#9aa2ff` by night.
- **Wording:** first person, framed as Arya's personal map of projects ("an atlas of things I've built", "Bring the idea. Leave with the finished thing.").
